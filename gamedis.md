# Sky Bounce — Game Design Document

---

## 1. Концепция

Sky Bounce — браузерный бесконечный платформер в духе Doodle Jump, реализованный на чистом TypeScript + Canvas без сторонних игровых движков. Игрок управляет персонажем, который автоматически отпрыгивает от платформ и должен продержаться как можно дольше, не упав за нижний край экрана. Платформы равномерно движутся сверху вниз («конвейер»), создавая иллюзию бесконечного подъёма. За каждое приземление начисляются очки; по мере роста счёта игра ускоряется, повышая напряжение и требуя более точной реакции.

---

## 2. Игровые состояния и переходы

| Состояние | Описание | Условие перехода |
|---|---|---|
| **MENU** | Стартовый экран. Персонаж выполняет циклическую анимацию прыжка на стартовой платформе. В центре экрана крупная кнопка **START**. | Клик по START (мышь) или нажатие Пробел / Enter → переход в **PLAY** |
| **PLAY** | Активная фаза. Работают физика, генерация платформ, подсчёт очков, обработка ввода с клавиатуры. | Центр персонажа пересекает нижнюю границу видимой области → переход в **GAME_OVER** |
| **GAME_OVER** | Игровой цикл остановлен. На экране: «Ваш счёт: X», «Ваш лучший счёт: Y», кнопка **REPLAY**. | Клик по REPLAY или нажатие Пробел / Enter → полный сброс сессии → переход в **PLAY** |

---

## 3. Логика персонажа

- **Стартовая позиция.** Центр нижней трети экрана, строго на стартовой платформе.
- **Вертикальное движение.** Автоматическое. При касании платформы сверху персонаж мгновенно получает импульс прыжка вверх. Игрок прыжком не управляет.
- **Горизонтальное движение.** Управляется только клавишами стрелок. Скорость постоянна (см. раздел «Параметры баланса»).
- **Гравитация.** Постоянное ускорение вниз применяется каждый кадр в состоянии PLAY.
- **Коллизия с платформами.** Срабатывает только при падении сверху. Проход сквозь платформу снизу или сбоку не блокирует движение и не засчитывается как приземление.
- **Условие проигрыша.** Если центр персонажа выходит за нижнюю границу видимой области → сессия завершается, переход в GAME_OVER.

---

## 4. Логика платформ и генерации

### 4.1 Принцип «конвейера»

Платформы появляются за верхней границей экрана и равномерно смещаются вниз с постоянной скоростью. Камера статична — движется именно мир, а не точка зрения.

### 4.2 Стартовая конфигурация

На старте генерируется фиксированное количество платформ, равномерно заполняющих видимую область по вертикали с постоянным шагом. Первая платформа — широкая стартовая, гарантирующая первый прыжок.

### 4.3 Спавн и удаление

- **Спавн.** Новая платформа создаётся строго выше видимой области. Координата X выбирается случайно в допустимом диапазоне с учётом ширины платформы и минимального отступа от краёв (`W_edge`).
- **Удаление.** Платформа удаляется из памяти, когда полностью выходит за нижнюю границу экрана.

### 4.4 Ускорение

Каждые `ACCEL_STEP_SCORE` набранных очков базовая скорость движения всех платформ увеличивается на фиксированный процент. Одновременно может сокращаться интервал между спавном новых платформ. Ускорение линейное или ступенчатое; максимальная скорость ограничена конфигом.

### 4.5 Типы платформ

| Тип | Вероятность спавна | Внешний вид | Поведение |
|---|---|---|---|
| **Статичная** | ~75% | Зелёная, без особенностей | Прыжок без последствий |
| **Ломающаяся** | ~25% (`BREAKABLE_PLATFORM_CHANCE`) | Другой цвет (трещины / красный оттенок) | При приземлении: +100 очков, запускается таймер разрушения (`BREAKABLE_DELAY_MS`), платформа мигает или меняет прозрачность; по истечении таймера — удаляется. Если персонаж ещё на платформе в момент разрушения — начинает падение |

> Очки за ломающуюся платформу начисляются стандартно (+100) в момент приземления, а не разрушения.

---

## 5. Очки, рекорды и цикл сессии

- **Начисление.** +`SCORE_PER_LAND` очков строго в момент успешного приземления на платформу.
- **HUD.** Текущий счёт отображается в верхней части экрана и обновляется мгновенно.
- **Сброс.** При переходе в GAME_OVER текущий счёт фиксируется для отображения, затем обнуляется при следующем рестарте.
- **Рекорд.** Хранится в `localStorage`; обновляется только если новый счёт строго больше предыдущего; не обнуляется при рестарте или перезагрузке страницы.
- **Экран проигрыша.** Формат: `Ваш счёт: X / Ваш лучший счёт: Y`, где X — очки последней сессии, Y — максимум за всё время.

## 6. Управление (только клавиатура)

| Клавиша | Действие |
|---|---|
| `←` | Зажатие → постоянное движение влево; отпускание → остановка |
| `→` | Зажатие → постоянное движение вправо; отпускание → остановка |
| Пробел / Enter | Старт (MENU) или рестарт (GAME_OVER) |

---

## 7. Граничные условия и правила

| Параметр / Правило | Описание |
|---|---|
| **H_min** | Минимальный вертикальный зазор между платформами; если нарушен — прыжок до следующей платформы физически невозможен |
| **W_edge** | Платформы не спавнятся ближе `W_edge` к боковым границам экрана |
| **Ресайз окна** | Сохраняется соотношение сторон; логика масштабируется пропорционально; физика и параметры спавна неизменны |
| **Приоритет коллизии** | Если персонаж одновременно касается платформы и пересекает нижнюю границу — приоритет у коллизии: прыжок засчитывается, игра продолжается |
| **Без перезагрузки** | Весь цикл MENU → PLAY → GAME_OVER → PLAY работает без перезагрузки страницы и запросов к серверу |

## 8. Параметры баланса

| Константа | Значение по умолчанию | Описание |
|---|---|---|
| `SCORE_PER_LAND` | `100` | Награда за приземление на платформу |
| `BASE_SCROLL_SPEED` | `50 px/s` | Начальная скорость движения «конвейера» |
| `ACCEL_STEP_SCORE` | `500` | Через сколько очков включается следующий шаг ускорения |
| `JUMP_FORCE` | `-450` | Импульс прыжка (отрицательный = вверх) |
| `GRAVITY` | `800` | Ускорение свободного падения, px/s² |
| `MOVE_SPEED` | `300 px/s` | Горизонтальная скорость персонажа (стрелки) |
| `BREAKABLE_PLATFORM_CHANCE` | `0.25` | Вероятность спавна ломающейся платформы (25%) |
| `BREAKABLE_DELAY_MS` | `750` | Время от приземления до разрушения ломающейся платформы, мс |

## Предлагаемые концепции и сеттинги

### Гравитационный беглец по снам

#### Идея и сеттинг

Игрок управляет существом, застрявшим в бесконечном цикле снов, где каждый уровень — отдельный мир с собственными и постоянно меняющимися законами гравитации. Цель не просто пройти платформинг, а научиться «переписывать» физику сна, чтобы вырваться из цикла.

Жанр: 2D платформер с базовым управлением (движение, прыжок, инерция). Ключевая механика — **гравитация**, которая не фиксирована и является частью дизайна каждого уровня.

#### Уникальная физика снов

Каждый сон вводит уникальную физику:

- **Перевёрнутая гравитация** — игрок «падает вверх», потолок становится полом.
- **Боковая гравитация** — притяжение влево или вправо, стены становятся поверхностями.
- **Вращающаяся гравитация** — направление «низа» постоянно меняется.

#### Адаптация сна и фрагменты

По мере прохождения игрок развивает «адаптацию сна»: способности быстрее привыкать к правилам, видеть безопасные поверхности, находить скрытые маршруты и собирать фрагменты сна.

Структура: последовательность снов — от обучения базовым искажениям до полного хаоса. Финал — пробуждение с элементами непредсказуемости.

---

#### Основная цель уровня

Собрать заданное количество **осколков сна**, чтобы открыть дверь выхода.

#### Завершение уровня

После сбора всех осколков активируется финальная дверь. Игрок проходит финальный участок платформинга и переходит в следующий сон.

#### Финальная секция

- Длительность: **30–60 секунд**.
- Новых осколков нет.
- Акцент на потоке движения и освоенной гравитации.

---

#### Механика: осколки сна

**Определение.** Временный collectible-объект, задающий ритм прохождения уровня.

**Поведение системы:**
- Активен только **1 осколок** одновременно.
- Исчезает при пропуске или сборе.
- Новый появляется через **3–6 секунд**.

**Типы спавна:**

| Тип | Описание |
|---|---|
| Фиксированный | Осколок всегда появляется в заданной точке |
| Маршрутный | Осколок движется по заданному маршруту |
| Условный | Осколок появляется только при выполнении условия (опционально) |

**Типы размещения:**

| Тип | Описание |
|---|---|
| On-path | Осколок на естественном маршруте движения игрока |
| Timing | Осколок требует точного выбора момента |
| Risk/Reward | Осколок в опасном месте с дополнительной наградой за риск |
| Flow | Осколок поддерживает темп и ритм движения |

---

#### Управление

**Принцип неизменности:** управление не меняется — меняется только направление гравитации.

| Ввод | Действие |
|---|---|
| `←` / `→` | Движение вдоль текущей поверхности |
| Кнопка прыжка | Прыжок против текущей гравитации |

**Особенности:**
- **Движение:** плавный разгон и торможение вдоль поверхности.
- **Прыжок:** против гравитации; высота зависит от длительности удержания кнопки.
- **Воздушный контроль:** 60–70% эффективности от наземного движения; ограниченная коррекция траектории в воздухе.

**Системы прощения:**

| Система | Описание |
|---|---|
| Coyote Time | Прыжок засчитывается в короткий промежуток после схода с края платформы |
| Jump Buffer | Нажатие прыжка чуть до приземления засчитывается при касании поверхности |
| Sticky Surface | Небольшое «прилипание» к поверхности при скользящем контакте |

---

#### Гравитация

**Определение:** вектор, задающий направление «низа», ориентацию персонажа и прыжковую ось.

| Направление гравитации | Эффект |
|---|---|
| Вниз | Стандартное поведение: пол внизу |
| Вправо | Стены справа становятся полом; движение «вверх» ощущается как движение влево |
| Вверх | Потолок становится полом; инверсия всех паттернов |

---

#### Механика проигрыша (Final)

**Идея:** смерть = локальный откат, а не перезапуск всего уровня.

**Триггеры смерти:** контакт с опасностью, падение в пропасть, ловушки.

**Поведение при смерти:**

- Респавн перед последним препятствием или в начале текущей секции.
- Потеря **1 последнего собранного осколка сна**.
- Если осколков не собрано — только респавн, без потери прогресса.

**UX-эффект:** визуальный эффект «рассыпания сна», короткое затемнение экрана, мгновенный возврат в точку респавна.

---

#### Структура уровня

- Длительность: **4–5 минут**.
- Состав: **6–8 секций** продолжительностью **20–60 секунд** каждая.

**Типы секций:**

| Секция | Роль |
|---|---|
| Intro | Вводит новую гравитацию, безопасная зона |
| Learn | Базовые препятствия с новой физикой |
| Develop | Усложнение, комбинации паттернов |
| Combine | Смешение нескольких механик |
| Pressure | Высокий темп, минимум ошибок |
| Recovery | Снижение давления, «дыхание» |
| Finale | Кульминация, открытие двери выхода |

---

#### Уровни 1–3

##### Уровень 1 — «Знакомый сон»

| Параметр | Значение |
|---|---|
| Гравитация | Вниз (стандартная) |
| Роль | Обучение |
| Особенности | Простая геометрия, минимальный риск, плавный темп |
| Туториал | Короткий текст + визуальные подсказки |
| Задача игрока | Понять управление, механику осколков, ритм сбора |

##### Уровень 2 — «Сломанная ориентация»

| Параметр | Значение |
|---|---|
| Гравитация | Вправо |
| Пол | Слева |
| Особенности | Вертикальное движение, дезориентация, узкие проходы |
| Туториал | Объяснение через окружение, минимум текста |
| Задача игрока | Переучивание, принятие новой системы координат |

##### Уровень 3 — «Отражённый мир»

| Параметр | Значение |
|---|---|
| Гравитация | Вверх |
| Особенности | Инверсия паттернов, повышенная точность, динамика |
| Туториал | Нет; навык проверяется через окружение |
| Задача игрока | Закрепление навыков, применение всего освоенного |

---

#### Интерлюдии между уровнями

- Короткая сцена смены гравитации.
- Визуальный переход (эффект «разлома сна»).
- Без текста и пояснений — только ощущение.

#### Кривая обучения

```
Понимание → Дезориентация → Контроль → Поток
```

Каждый уровень проводит игрока через весь цикл заново с новой гравитацией, постепенно сокращая фазы Понимания и Дезориентации и удлиняя фазы Контроля и Потока.
