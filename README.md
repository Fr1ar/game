# Sky Bounce

Простая браузерная игра на TypeScript в духе Doodle Jump. Игрок автоматически прыгает вверх, а задача сводится к тому, чтобы попадать на платформы и набирать высоту.

## Запуск

1. Установить зависимости: `npm install`
2. Запустить локальный сервер: `npm run dev`
3. Открыть адрес, который покажет Vite, обычно `http://localhost:5173`

## Управление

- `A` / `D`
- `←` / `→`
- `Space` после проигрыша для рестарта

## Сборка

`npm run build`
